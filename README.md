## ✨ Features

- 💜 **Cyber-Neon Aesthetics:** Glowing purple accents and modern glassmorphism design.
- 🌐 **Dual Language Support:** Seamless **English / Turkish** instant toggle with `localStorage` memory.
- 🖼️ **Live Rscripts Card:** Real-time embedded user card integration.
- ⚡ **Interactive Hover Effects:** Custom brand-matching neon glows for each social platform.
- 📱 **Fully Responsive:** Smooth experience across mobile, tablet, and desktop viewports.
